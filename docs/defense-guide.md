# 第八周展示与答辩提纲

建议按[九分钟操作顺序](student-confirmation.md)练习，准备两套终版案例和本机运行环境。

## 需要讲清楚的问题

1. 用户是谁，姓名、年龄、兴趣等输入怎样影响故事？
2. JSON为什么要校验？格式异常、超时和API失败怎样处理？
3. 角色外貌描述与固定Seed各起什么作用，有哪些局限？
4. 三位故事角色和旁白如何选择音色，情绪参数怎样传到TTS？
5. 音频、字幕和视频为什么共用时间轴，怎样防止正文更新后使用旧媒体？
6. 文本TF-IDF与图像CLIP分别检索什么，有限中文词典有什么限制？
7. LangChain注册了哪些工具，模型规划与固定规则有什么区别？
8. 森林案例的合作结尾指令如何影响最后一幕，哪些内容保持不变？
9. 为什么采用本机存储、异步任务、缓存和输入哈希？
10. 协作过程中各工具与本人分别承担什么工作？记录见[协作日志](../ai_log.md)。

## 使用的终版

- forest-final-20261028：6张API图，8页PDF，4种音色，414.264秒音频，约414.26秒视频，108条字幕。
- ocean-final-20261028：6张API图，8页PDF，4种音色，419.04秒音视频，107条字幕。

现场至少展示三种关联模态，不只播放录屏。展示预生成结果时说明生成时间与来源，实际操作阅读、播放和检索；新图片生成需先核对账号额度。
