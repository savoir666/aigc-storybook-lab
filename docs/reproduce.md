# 完整工程复现与D盘使用

## 本机已有原项目

本人的原项目在`D:\AIGC作业\outputs\storybook-lab`，密钥、模型和成品已经在D盘，不需要再次下载或生成。双击`D:\AIGC作业\双击启动故事屋.cmd`使用它。

## 从GitHub下载的新副本

1. 克隆或解压整个仓库到D盘。推荐Python3.12，双击`启动故事屋.cmd`；首次需要安装requirements.txt依赖，缓存与虚拟环境在项目目录中。
2. 第1周入口为`http://127.0.0.1:8766/trae-story.html`；完整主应用为`http://127.0.0.1:8766`。若原服务已占8766，先确认使用哪一份，不要同时启动。
3. 使用项目`.venv/Scripts/python.exe`执行`python scripts/restore_sample_cases.py`（将python换成该环境实际解释器路径），再刷新书架，可离线浏览两套已生成图文和下载音视频。不需要重新调用模型。
4. 第6周真实CLIP需要本地模型。原电脑已有模型时，可在停止服务后将原项目`data/models/clip`整个目录复制到新项目对应目录；无需重复下载。全新电脑运行`python scripts/setup_clip.py`，从脚本固定版本来源下载公开CPU ONNX模型到本项目D盘目录。首次下载需要网络；权重不进Git。
5. 启动后进行“太空火箭”“海底珊瑚”等检索，检查界面实际使用的引擎。缺权重时会明确降级，不能把降级结果当作CLIP推理证据。
6. 只有要生成新故事/新图片时才在本机设置中填写自己的密钥。文字测试不验证图片服务；百炼免费配额和“用完即停”由本人在平台确认，不能保证所有账号都有免费额度，不充值、不默认启用付费调用。

## 校验

`python scripts/verify_submission.py`校验两个案例的55个文件SHA和两份故事绑定，不联网、不调用模型。`python -m pytest tests -q`运行工程测试；模拟接口测试只验证逻辑，不代表新的模型调用。
