# 角色音色与情感参数方案

角色的声音在全书内保持固定，情感参数按每句`dialogues[].emotion`调整。至少三个实际说话角色使用三种不同音色。

| 角色 | 固定音色 | 设计意图 |
|---|---|---|
| 旁白 | zh-CN-XiaoxiaoNeural | 平稳讲述，帮助儿童理解场景 |
| 主角小狐狸 | zh-CN-YunxiNeural | 与旁白可区分的主角声音 |
| 伙伴米粒 | zh-CN-XiaoyiNeural | 与主角、旁白均不同的伙伴声音 |
| 成年向导：树园丁 / 鲸鱼爷爷 | zh-CN-YunyangNeural | 第三位故事人物使用独立音色；旁白另计 |

| 脚本情绪关键词 | rate（语速） | pitch（音调） | volume（音量） |
|---|---|---|---|
| 温柔、好奇及未识别情绪 | -8% | +0Hz | +0% |
| 兴奋、开心、快乐、高兴 | +3% | +4Hz | +0% |
| 低语、轻声 | -15% | -4Hz | -8% |
| 担心、害怕、紧张、悲伤 | -12% | -3Hz | +0% |
| 坚定、勇敢、鼓励 | -3% | +1Hz | +0% |

实现为`media.speech_prosody`，由`_save_speech`实际传入Edge TTS。新的生成任务会在每段音频的`audio-proof.json.parts`及时间轴`segments`保存情绪和实际参数。旧样例的证明文件如果没有这些字段，说明它是在本次情感参数改进前生成，不能倒填为已经使用新参数。

这是语速、音调和音量的韵律模拟，不等同于服务原生情感风格控制，也不保证听感一定自然。最终请本人试听，核查情绪、角色辨识度、停顿与年龄适配，再按需要修改脚本文本或参数。

音频按真实PCM样本数计时；Web高亮、SRT字幕和视频使用同一时间轴。音频生成失败时明确报错，不用静音补足三分钟。
