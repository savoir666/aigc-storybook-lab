# 操作检查与第八周展示指南

2026-10-29：本人已确认个人反思，并反馈两套成品“没问题”，详见[确认记录](ai-logs/student-reflection.md)。接下来保存仓库上传截图，确认课程提交入口，并练习现场展示。

## 展示前检查

1. 按[复现说明](reproduce.md)启动应用，确认服务可访问、书架可打开两套最终案例。
2. 从[作品目录](../outputs/README.md)检查PDF、MP3和MP4，关注角色外观、图文对应、朗读区分、字幕与音画同步。
3. 试用三个主题和素材检索，确认CLIP实际加载状态；未加载时按说明准备模型。
4. 截取GitHub仓库名、文件列表和README，保存为上传证明。截图不含密钥。
5. 确认课程平台是否有Classroom邀请，按老师指定入口提交仓库与第一周视频附件。

## 九分钟练习顺序

|时间|操作与讲解|
|---|---|
|0:00—1:00|项目目标、阅读对象、三主题及关联模态|
|1:00—2:00|现场填写信息并生成模板示例|
|2:00—3:30|打开真实森林案例，展示分镜、一致性对比和PDF|
|3:30—4:30|播放音频与同步文字，说明角色音色与韵律参数|
|4:30—5:30|播放故事视频片段，展示配音、音乐和字幕|
|5:30—6:30|现场自然语言检索，说明TF-IDF与CLIP区别|
|6:30—7:30|展示Agent架构、两个案例轨迹及合作结尾干预结果|
|7:30—9:00|解释缓存、错误处理、成本控制及协作分工，预留问答|

课程要求8—10分钟现场运行，预生成案例应说明来源。线上生成耗时较长，演示中可使用已有作品并实际操作阅读、检索和播放。协作分工与个人记录统一见[协作日志](../ai_log.md)。
