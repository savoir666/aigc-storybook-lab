## 采用与改进

新版本采用角色扮演作为默认策略，理由是本轮输出的目标与分镜较易跟随；不据单次实验宣称它普遍优于其余策略。工程上新增以下约束：

1. 主角年龄和目标读者年龄分别输入，后者控制用词和句长。
2. 旁白只叙述，所有直接发言分配给真正的角色；除旁白外要求主角、伙伴、成年向导三位人物有独立对白。
3. 首次出现交代身份，困难后必须写出具体解决过程；不让低龄主角独闯沉船、硬闯尖刺或搬重物，遇险先停止并请可信成人帮助。
4. 配音前保留模型原始响应、规范化和压缩记录；最终正文与音频、字幕、绘本使用相同分段，实际观看和试听仍是必要质量检查。

这些改动是根据本轮缺陷提出的下一轮方案；新案例成功不等于严格消融实验已经证明每条约束的单独效果。学生可以在阅读原始三份输出后补充自己的判断，无需把AI助理观察写成本人独立评分。
